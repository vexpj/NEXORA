# Сборка и проверка установщика NEXORA

## Сборка
1. Установите .NET 10 SDK и Inno Setup 6: `winget install JRSoftware.InnoSetup`
2. В PowerShell из корня проекта: `.\build\build.ps1`
   (если запрещены скрипты: `powershell -ExecutionPolicy Bypass -File .\build\build.ps1`)
3. Результат в папке `dist\`: `NEXORA.exe`, `NEXORA-Setup.exe`, `NEXORA.ico`.

Иконку можно пересоздать: `python build/make_icon.py` (нужен `pip install pillow`).

## Чеклист проверки на чистой Windows 10/11 x64
Используйте виртуальную машину без установленного .NET (Hyper-V / VirtualBox) или Windows Sandbox (только Pro/Enterprise).

- [ ] `NEXORA.exe` запускается напрямую без установленного .NET
- [ ] `NEXORA-Setup.exe` запрашивает права администратора и ставит в `C:\Program Files\NEXORA`
- [ ] Есть ярлык в меню «Пуск»; ярлык на рабочем столе создаётся при включённой галочке
- [ ] NEXORA есть в «Параметры → Приложения → Установленные приложения», с иконкой
- [ ] Установленный лаунчер запускается, иконка окна и панели задач — NEXORA
- [ ] Настройки сохраняются после перезапуска (`%AppData%\NEXORA\settings.json`)
- [ ] Установка новой версии поверх старой (повысьте `<Version>` в `Directory.Build.props`) обновляет файлы, ярлыки не дублируются
- [ ] Удаление убирает папку в Program Files, ярлыки и запись в списке программ; `%AppData%\NEXORA` и `%AppData%\.nexora` остаются

## Известные ограничения
- Подпись кода (Authenticode) не настроена: Windows SmartScreen покажет предупреждение для неподписанного установщика. Сертификат нужен до публичного релиза.
- Автообновление из самого лаунчера появится на этапе 10; текущий установщик уже умеет обновлять установку поверх (общий AppId).
