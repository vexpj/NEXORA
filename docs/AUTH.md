# Вход через Microsoft: как получить Client ID

NEXORA не хранит секретных ключей и не спрашивает пароль. Вход идёт в браузере (OAuth 2.0 + PKCE),
поэтому нужен только **публичный Application (client) ID** вашего приложения Azure.
Чужие Client ID использовать нельзя.

## 1. Регистрация приложения (бесплатно)
1. Откройте https://portal.azure.com → «Microsoft Entra ID» → «Регистрация приложений» → «Новая регистрация».
2. Имя: `NEXORA`. Поддерживаемые типы учётных записей: **«Любой каталог Entra ID и личные учётные записи Microsoft»**
   (или только личные учётные записи Microsoft).
3. Redirect URI: платформа **«Мобильные и классические приложения»** (Public client), значение `http://localhost`.
4. После создания откройте «Проверка подлинности» → включите **«Разрешить общие клиентские потоки»** → Да → Сохранить.
5. Скопируйте **«Идентификатор приложения (клиента)»** на странице «Обзор».

## 2. Одобрение Mojang (обязательное условие Minecraft API)
По сведениям Mojang/Microsoft, новые приложения должны пройти проверку, иначе сервис Minecraft отвечает
отказом (403, «Invalid app registration») при входе. Заявка: https://aka.ms/mce-reviewappid
Актуальные требования смотрите на https://minecraft.wiki/w/Microsoft_authentication — правила могут меняться.
Пока заявка не одобрена, вход в NEXORA завершится сообщением об этой ошибке; остальные функции лаунчера работают.

## 3. Где вставить
NEXORA → «Настройки» → «Microsoft Client ID» → «Сохранить» → вкладка «Аккаунт» → «Войти через Microsoft».

# CurseForge API-ключ
Бесплатный личный ключ: https://console.curseforge.com. Вставьте его в «Настройки». Он хранится на диске
только в зашифрованном виде (Windows DPAPI). Modrinth работает без ключа.
Часть модов на CurseForge запрещена автором к скачиванию вне сайта — для них NEXORA покажет сообщение и кнопку «Страница».
